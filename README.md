# Student Performance Analysis Using Machine Learning

## Overview

This project focuses on analyzing student academic performance data to uncover patterns that influence learning outcomes. Using machine learning and statistical analysis, the project evaluates subject-wise performance, score consistency, and risk levels among students.

The goal is to demonstrate how data analysis and machine learning techniques can be applied to educational data to extract insights and support performance prediction.

---

## Dataset

The dataset used in this project is a publicly available and well-documented student performance dataset. It contains subject scores and related academic attributes suitable for analysis and modeling.

---

## Tools and Technologies

- Python  
- Pandas and NumPy  
- Matplotlib and Seaborn  
- Scikit-learn  
- Jupyter Notebook  

---

## Methodology

The project follows a structured analytical workflow:

1. Data preprocessing and cleaning  
2. Exploratory data analysis (EDA)  
3. Risk categorization based on performance and consistency  
4. Feature selection and model development  
5. Model evaluation and interpretation  

Each step is implemented clearly to ensure transparency and reproducibility.

---

## Key Insights

- Students who complete test preparation programs generally achieve higher average scores.
- Mathematics shows comparatively lower performance, indicating higher difficulty.
- High-risk students typically display low scores along with inconsistent academic performance.
- Score consistency emerges as a reliable indicator of overall academic stability.
- Many medium-risk students remain consistent but perform below expected levels.
- Differences in subject-wise score variability suggest an imbalance in curriculum difficulty.

---

## Outcomes

The project demonstrates how machine learning can be used to:

- Identify at-risk student groups  
- Evaluate subject difficulty through performance trends  
- Analyze academic stability using score consistency  
- Build a basic predictive model for student performance
